# Contributing

Use Node.js 22 or later. No package installation is required.

1. Run `npm start` and open the printed local address.
2. Make a focused change and check it in the browser.
3. Run `npm run check` and `npm test`.

Edit historical copy in the JSON files listed in [Sources](docs/SOURCES.md).
Run `npm run content` afterward and commit the JSON and module changes together.

Historical claims need a source that supports that specific claim. Include a
page or object number when possible. Do not transfer an object's date,
dimensions, materials or provenance to a similar-looking digital model.
Distinguish visible surface regions from historical construction methods and
unmodeled internals. Keep uncertain identifications explicit.

New assets need a recorded creator, source URL, redistribution license and
any required attribution. Keep the model-specific terms separate from the code
license. Never commit credentials, local account information or hosting secrets.

For viewer changes, check assembled and separated geometry, isolation, camera
reset, close-ups, both themes and a narrow phone layout. For content changes,
check the source links and any feature jump targets.
